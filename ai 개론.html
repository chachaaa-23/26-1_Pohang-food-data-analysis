Pohang Food Store Analysis Project

포항 음식 상권 분석 프로젝트 역할 분담

소상공인 상가정보 API 데이터를 기반으로 포항시 음식 상가를 수집·시각화·클러스터링하여 행정동별 상권 특성을 해석한다.

A

데이터 완성

API 수집, 음식 업종 필터링, 결측치 정리, 최종 CSV 생성

B

지도·그래프 제작

음식 상가 분포 지도와 행정동별 업종 구성비 시각화

C

클러스터링 분석

KMeans와 PCA로 비슷한 상권 유형을 묶고 해석

팀원별 역할

A

API 데이터 수집 및 전처리

역할: 분석에 사용할 최종 CSV를 만드는 사람

할 일

  • 소상공인 상가정보 API 사용법 확인
  • 포항시 상가 데이터 수집
  • 음식 관련 업종만 필터링
  • 필요한 컬럼만 남기기
  • 결측치 확인
  • 위도/경도, 행정동, 업종명이 비어 있는 행 제거 또는 정리
  • 최종 데이터 파일 저장

최종 결과물

  • pohang_food_stores.csv

포함할 컬럼

  • store_name
  • category_main
  • category_mid
  • category_sub
  • dong
  • address
  • latitude
  • longitude
B

지도 시각화 + 업종 구성비 그래프

역할: 데이터가 실제로 어떤 분포를 가지는지 보여주는 사람

할 일

  • A가 만든 CSV 불러오기
  • 음식 상가 위치를 지도에 표시
  • 업종별로 색상 다르게 표시
  • 행정동별 음식 상가 수 집계
  • 행정동별 업종 구성비 계산
  • 누적 막대그래프로 시각화
  • 그래프에서 보이는 특징 정리

최종 결과물

  • pohang_food_map.html
  • dong_category_ratio.png

설명할 내용

  • 어느 지역에 음식 상가가 몰려 있는가?
  • 행정동별로 어떤 업종 비율이 높은가?
C

KMeans, PCA, 클러스터 해석

역할: 수업에서 배운 AI 모델을 적용하는 사람

할 일

  • 행정동별 업종 비율 테이블 만들기
  • KMeans로 행정동들을 비슷한 상권끼리 묶기
  • k=3 또는 k=4 정도로 실험
  • PCA로 2차원 산점도 만들기
  • 각 클러스터의 업종 특징 확인
  • 클러스터 이름 붙이기

예상 클러스터 이름

  • 카페/주점 중심형
  • 한식/시장 중심형
  • 주거지 생활형
  • 대학가/외곽형

최종 결과물

  • cluster_result.csv
  • pca_cluster_plot.png

설명할 내용

  • 비슷한 업종 구성을 가진 행정동들이 어떻게 묶였는가?
  • 각 클러스터는 어떤 상권 유형으로 해석할 수 있는가?

프로젝트 진행 흐름

1단계 · A

포항시 음식 상가 데이터를 수집하고 정제하여 분석 가능한 CSV 파일을 만든다.

2단계 · B

A의 CSV를 기반으로 지도와 업종 구성비 그래프를 제작해 데이터의 공간적·구성적 특징을 보여준다.

3단계 · C

B가 만든 행정동별 업종 비율을 기반으로 KMeans와 PCA를 적용해 상권 유형을 해석한다.

핵심 구조: A가 데이터 완성 → B가 지도/그래프 제작 → C가 클러스터링 분석
